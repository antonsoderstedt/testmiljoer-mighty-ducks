Firebase behöver konfigureras

För att datan ska delas i realtid behövs ett Firebase Realtime Database-projekt. Följ stegen nedan och uppdatera sedan FIREBASE_CONFIG längst ner i index.html.

1. Gå till console.firebase.google.com → Skapa projekt (gratis).

2. Bygg → Realtime Database → Skapa databas → Testläge (public read/write).

3. Projektinställningar → Dina appar → Webbapp → Registrera → kopiera config-objektet.

4. Klistra in värdena i FIREBASE_CONFIG i index.html och pusha.
